# 专家意见补充验证协议

沿用MSC-GP的估计/告警/保护公式及三档冻结参数；不从已有验证结果重新选择本文参数。仅在原10 Hz开发种子上细化RIT和固定协方差项对照，并在运行新对照验证前保存配置与哈希。

1. RIT：原候选保留，20–120 s区间以1 s步长补充，覆盖原三个最优配置及相邻区间；筛选仍为开发全程峰值不超过任务80%，最小测距工作量。不宣称全局最优。
2. 固定协方差项：从原开发MSC-GP逐秒预测界分别取位置/速度的10/25/50/75/90/95/97.5/99/99.5/100百分位常数（各任务独立），保留同档保护速度及门限比例。以同一80%判据筛选；另报告中位常数配置作为不重新调参消融。常数预测没有在线协方差信息。初始五分位候选在中间档未通过开发裕量，故在任何新验证运行前扩展高分位候选；开发失败记录保留。
3. 未见几何：目录中排除原64个NORAD，按相同几何筛选程序再选64个独立目标。冻结参数后才运行。三事件时刻分别在80–120、265–335、465–535 s确定性随机；每次60 s。每个事件轮次独立平衡置换八幅度和三方向，取消原目标索引的绑定。
4. 已见几何对照沿用原四频率×三种子以便配对；未见几何用四频率×三新种子261001401/402/403。每套每任务768轨迹。所有方法统一[30,700)全历元，保留迟报与未检出。
5. 同起点旁路：10 Hz每整数秒，从真实控制更新前状态复制估计器，使用同一未来量测仅测角重放下一秒，记录真实位置/速度最大误差、原始预测、保护预测及低估。该分支不影响控制。覆盖全部64目标，原几何/未见几何各首种子，三任务。
6. 检测曲线：10 Hz，名义无机动预算0.25/0.5/1/2次每目标小时，以相同确认、抑制、复位标定。使用3个额外无机动种子增加独立暴露；按同一独立检查得到的实际误警率画曲线。MSC和SS8重点对照，全部四窗口保留分层数据。方向及初始距离/LOS角速度分组，配对时延差按目标簇Bootstrap。
7. 非理想服务：10 Hz原几何三种子，三主控制+固定项，共同0/0.5/1/2 s请求响应延迟与每200 s固定10/30 s成段丢测。延迟指请求延迟后在当前历元返回同步量测，不引入异步旧量测；原初始化前30 s保持一致，服务扰动从30 s起。相同服务规则与噪声。报告任务越限、请求连续窗口次数、请求时间、有效量测时间。
8. 告警消融：关闭对主滤波过程噪声及额外测距的告警干预，光学检测照常统计；其余保持不变。

论文聚焦任务精度约束下的保护测距调控；多尺度尚未证明优于合理单窗口、IMM多数RMSE更低的结论继续保留。所有新结果及不利结果均报告，不提前假定优越性。仅本地S1，不公开上传。

## 本轮追加协议

在不改变原模型和主参数的情况下，补充明确仅激光服务缺失；光学与检测窗口持续。失败分析以64目标为簇，报告每目标12相关轨迹的比例以及目标级二元终点，后者使用双侧精确配对检验。触发计数由已保存的决策前保护量及实际cmd重算，初始化与告警不混入常规支路归因。

固定周期在原开发种子补齐31–110 s、1 s窗口的周期，并分别检验四相位共同可行与各相位分别可行（共同80%双峰值判据）。共同规则按四相位平均时间最小选周期、验证相位0；分别规则在每相位独立筛选。全部配置在补充验证前冻结，验证为10 Hz两几何各3种子。所选110 s为局部搜索边界，不能称全局最优；不得根据验证失败重新选择。无新增目标、机动类型或硬件假设。
